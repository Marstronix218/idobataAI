# Idobata beta reel — Sora prompts

All jobs use `sora-2-pro`, 1024x1792, and 4 seconds. If the requested model is unavailable, the runner retries with `sora-2`.

## Universal negative block

Append to every prompt:

> THIS IS ONLY A CINEMATIC PERFORMANCE SHOT. Never generate readable phone text, chat messages, social media UI, Idobata UI, usernames, subtitles, captions, logos, floating words, notification text, RPG text, or fake app screens. If a phone is visible, its content must be unreadable, blurred, or angled away. Priorities: CHARACTER IDENTITY → FACIAL PERFORMANCE → SIMPLE MOTION → CLEAN COMPOSITION. Do not invent additional story beats.
